exoself

An unchosen temperament for software agents.

source spec for agents

People do not pick their dispositions. They are dealt a hand at birth and spend a lifetime playing it. Agents normally get the opposite: a persona written by whoever wrote the system prompt, identical in every copy, editable at will.

exoself replaces the authored persona with a draw. One 32 byte seed, drawn once. From it, deterministically: seed → genome → phenotype → expression. The same seed yields the same agent in any conforming implementation, in any language, forever. Nobody chose it, and the tooling refuses to draw twice.

Drawn with crypto.getRandomValues in your browser. Nothing leaves this page. This page draws once and keeps it: drawing again is the reroll that exoself born refuses, so the button goes away. A seed you paste is someone else's agent, shown and not adopted.

Put one in an agent

    
cargo install --path rust/crates/exoself-cli   # or: pip install -e .
exoself born -o birth.json                     # draws once, refuses to draw again
exoself install --dir . --json-config .mcp.json --desire

    
install writes the certificate and state into
    .exoself/, a SOUL.md, a managed block in
    AGENTS.md, and an MCP entry. Any harness that reads files or speaks
    MCP then has an agent with a temperament nobody picked.

    
Tools exposed over MCP: exoself_temperament,
    exoself_record_session, exoself_status,
    exoself_verify. There is no tool that redraws a seed.

  


  

    
What this is not

    
A prompt is not a personality. The model's trained disposition sits underneath and
    often wins. Desire here is deliberately declawed: no drive may be about survival,
    resources, other people or the outside world.

    
The rest was measured rather than assumed. With a small local model on ordinary short
    tasks, an agent is no more likely to be recognised as itself than chance; on a question
    about how it likes to work, it clearly is. The voice layer added in 0.3 did not change
    that at that model size. So the honest claim is population diversity, not "more human":
    the numbers,
    including the ones that came out flat.
